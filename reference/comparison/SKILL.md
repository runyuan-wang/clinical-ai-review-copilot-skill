# 多篇可比性与 gap

本模块可独立执行。输入各篇已定位的事实卡；输出可比较项、不可比较项、冲突/限制、未知和有边界的临床含义。不可比时不排 AUROC 英雄榜，不合并数字，不做 meta-analysis 式 pooling。

## 比较闸门

逐篇并排核对：人群与场景；标签/结局定义；预测时间窗；数据来源和同队列独立性；输入可获得时点；训练/内部或外部验证；比较基线；指标、CI、校准；阈值与错误成本；临床工作流和实施影响。任何关键维度不同，都写清“差异如何阻止比较”，而不是只加一句“需谨慎”。

可以比时也要说明比较单位（同一结局、时间窗、场景和验证层级）。不能把内部验证分数与独立外部验证分数当同一排行榜；不能用不同标签、不同队列或不同成本下的 AUROC 互相替代。

## 严格推导 gap

```text
Evidence：多篇原文实际报告了什么（位置）
→ Conflict/Limitation：哪里冲突、设计限制或比较条件不同
→ Unknown：因此仍不知道哪个具体问题
→ Clinical consequence：这对临床解释/实施/研究选择造成什么边界
```

只有 Unknown 对应明确缺口时，才提出下一步研究问题；不套用“未来需要多中心、大样本、前瞻性研究”。如果提出它，说明为什么解决该 unknown 需要它，并承认这只是候选方案。有限语料中的“所读文章未报告”不是全领域空白；novelty 必须另有检索范围、截止日期和覆盖披露。

## 可交付结构

先给“可比/部分可比/不可比”及理由，再给表格或短段。每个 gap 至少带一个原文位置和一个具体未知。冲突保留双方证据，不让多数论文投票消灭少数反证。若只有摘要或未读附录，降低比较强度并列待查。
