# 作者判断闸门

本模块可独立执行。它是协作规则，不是能防绕过的程序强制；因此必须明示当前状态：`未答`、`已答待核`、`作者确认` 或 `证据不足/冲突`。

## 用大白话提问

在给出技术审查和证据位置后，让作者逐篇回答，尽量用自己的话：

1. 这篇研究到底帮你理解或解决了什么临床问题？
2. 哪个结果对你的综述问题最有用，为什么？
3. 你愿意把它解释到哪一层：该队列、该时间窗、该验证场景，还是更宽？
4. 最大的疑问、异议或不能接受的外推是什么？
5. 这篇与另一篇能否直接比较？如果不能，差在哪里？
6. 根据证据，你现在认为合理的研究 gap 或临床含义是什么？哪些还只是未知？

记录作者原话或忠实摘要、对应证据位置、作者提出的反证/异议、尚未解决的问题。不要用术语熟练度代替判断；作者可以先说“不知道”。

## 闸门规则

- 未答：只返回证据材料、可选解释和候选问句，不替作者选观点、不写完成态综述正文。
- 已答待核：回原文逐点核验作者判断；支持、部分支持、冲突和未报告分开。
- 证据不足/冲突：保留作者判断为候选观点，主动弱化措辞或停下补材料；不能把“作者觉得重要”写成“研究已证明重要”。
- 作者确认：才可把已核判断转成学术化表达，并保留范围、位置和不确定性。

如果作者只要短解释，给短解释与一个小问题，不强迫大表或数学学习。医学价值、研究意义和最终立场始终由作者承担。
