# clinical-ai-review-copilot-skill v0.1.0

**临床 AI 文献审阅副驾驶**：让 AI 承担原文阅读、证据提取、技术质疑和生僻词解释；临床意义、研究价值与最终观点仍由作者判断。不是“上传文献就自动写完综述”，也不是必须先学一门机器学习课。

## 怎么开始

把本目录交给能读取文件的 AI，先让它读 [SKILL.md](SKILL.md)，再提供论文或可访问的原文及本次问题。例如：

> 调用临床 AI 文献审阅副驾驶。先用三句话说清这篇研究做了什么，只解释妨碍我判断的生僻词。指出证据支持到哪里，停在需要我判断的地方，不直接写综述。

多篇任务可以说：

> 对照这几篇研究，先查人群、标签、时间窗和验证方式能否比较，再提出有证据链的差异与未知；不要只按 AUROC 排名。

只有摘要也能做受限导读，但必须说明未读范围；完整审查需要可访问原文、相关图表和补充材料。包内没有自动检索器、后台执行器或固定模型依赖。实际取文献和调用外部工具，遵守当前工具与数据授权。

## 按需结构

- [SKILL.md](SKILL.md)：短入口与路由。只先读它，不要求一次加载全部文件。
- [证据与覆盖](reference/evidence/SKILL.md)：身份、版本、发表状态、阅读范围与原文定位。
- [术语解释](reference/terms/SKILL.md)：统计、方法学、计算机、缩写与跨科医学词，遇到什么解释什么。
- [技术审查](reference/technical-review/SKILL.md)：泄漏、验证、校准、比较与临床效用边界。
- [比较与 gap](reference/comparison/SKILL.md)：先可比性，再从证据推导有限的未知。
- [作者判断闸门](reference/author-gate/SKILL.md)：作者用自己的话判断，回原文核验后才组织综述句。
- [Reviewer #2](reference/reviewer2/SKILL.md)：有定位的反向质疑，不替代专业审稿。
- [examples.md](examples.md)：三组明确教学构造，不是真实论文试跑。
- [worksheet-template.md](worksheet-template.md)：可选工作卡，不必填满才开始。
- [NOTICE.md](NOTICE.md)：设计来源与许可边界。

## 本地使用与状态

一般文件型 Agent 可直接按相对链接读取本包。LingTai 使用者可把整个目录放入自己已配置的 custom 技能根，按自己的 Skills Manual 验证入口与每个子模块，并在下次自然重载时收入目录；文件存在不等于已经被运行时加载，不需要改共享根或账号配置。

这是公开的 v0.1.0 文件工作流，不是已验证产品。文件与内容检查不代表已经用真实论文验证过遵从度、综述质量或临床效果；未试跑真实 3–5 篇论文，未临床使用。公开可见不等于授予开源许可；本仓库目前未指定开源许可证。

首次真实使用后，反馈最有用的是：哪个词仍难懂、哪条技术判断找不到原文、哪个作者问题让你觉得 AI 在替你选观点。按这些具体卡点改进，不以结构校验通过冒充有效。
